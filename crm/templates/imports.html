Import RocketReach CSV

Pour importer un nouveau batch de prospects RocketReach :

  1. Place le CSV dans linkedin-scraper/data/inputs/
  2. Lance le pipeline triage : 
    cd linkedin-scraper && python -X utf8 scripts/triage_sites.py
python -X utf8 scripts/reclassify_triage.py
python -X utf8 scripts/triage_recheck.py
  3. Importe le CSV final dans le CRM : 
    python -X utf8 -m crm.import_prospects

Le script d'import détecte automatiquement le CSV le plus récent. Pour reset complet : --reset.

Pipeline complet (one-shot)

Pour traiter un nouveau CSV de bout en bout, depuis le RocketReach brut jusqu'au CRM :

cd linkedin-scraper

# 1. Place le CSV dans data/inputs/

# 2. Triage HTML scoring (sans_site / veillot / récent)
python -X utf8 scripts/triage_sites.py

# 3. Reclassification stricte
python -X utf8 scripts/reclassify_triage.py

# 4. URL discovery v2 sur les sans_site
python -X utf8 scripts/triage_recheck.py

# 5. WebSearch + apply manual URLs (si besoin)
python -X utf8 scripts/triage_apply_manual.py

# 6. Import dans le CRM
cd ..
python -X utf8 -m crm.import_prospects
